# 🌐 知识图谱关联总览

## 📊 所有概念索引

```dataview
TABLE 
  file.name AS "概念",
  tags AS "标签",
  length(file.inlinks) AS "被引用次数",
  length(file.outlinks) AS "引用次数"
FROM "概念"
SORT length(file.inlinks) DESC
```

## 🔗 引用网络可视化

```dataview
LIST 
  file.name + " → " + file.outlinks AS "引用关系"
FROM "概念"
WHERE length(file.outlinks) > 0
SORT file.name ASC
```

## 🌱 待生长节点（关联少于2个）

```dataview
LIST file.name AS "孤立节点"
FROM "概念"
WHERE length(file.inlinks) < 2 AND length(file.outlinks) < 2
```

## 📈 统计摘要

```dataview
CALENDAR file.mtime
FROM "概念"
```
