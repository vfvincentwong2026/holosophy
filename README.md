## 📖 这是什么？

**HoloSophy**（全息玄学）是一个实验性的开源知识库，试图用现代物理学的语言重新诠释东方玄学。

它将 **玄学 · 量子力学 · 天文学 · 历史地理** 四域知识编织成一张可计算的知识图谱。

🧠 **更重要的是：这是一个 Agent 孵化器。** 任何人都可以基于这个知识库，用提示词创建自己的 AI Agent。
